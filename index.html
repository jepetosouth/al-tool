AL-Tool

Android/Termux Terminal Interface

A terminal interface tool designed for Android-based penetration testing environments.

Fully compatible with Termux and NetHunter.

Quick Installation

Method 1: One-line Install (Recommended)

curl -sSL https://raw.githubusercontent.com/jepetosouth/al-tool/main/install.sh | bash

Or with wget:

wget -qO- https://raw.githubusercontent.com/jepetosouth/al-tool/main/install.sh | bash

Method 2: Termux Quick Install

pkg update && pkg install git curl -y && curl -sSL https://raw.githubusercontent.com/jepetosouth/al-tool/main/install.sh | bash

Method 3: Manual Install

git clone https://github.com/jepetosouth/al-tool.git cd al-tool chmod +x install.sh al-tool.sh ./install.sh

Usage

Interactive Mode

al-tool

Command-Line Mode

# Check dependencies al-tool --check # Install dependencies al-tool --install # Clone ALHacking repository al-tool --clone # Run ALHacking tool al-tool --run # Full automated setup al-tool --setup # Show environment information al-tool --info # Show help al-tool --help
